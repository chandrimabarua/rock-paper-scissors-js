# 👊 Rock Paper Scissors Game ✋✌️

A sleek, modern, and interactive **Rock Paper Scissors** web application built using **HTML5, CSS3, and JavaScript**. It features dynamic score tracking, detailed game statistics, a real-time match history log, and victory confetti animations.

---

## ✨ Features

- **Royal & Professional UI:** Custom styling with smooth transitions, subtle hover effects, and a modern color palette.
- **Real-Time Scoreboard:** Keeps live track of Player wins, Computer wins, and Draws.
- **Detailed Game Analytics:** Shows Total Games played, Win Rate percentage, and Best Win Streak.
- **Match History Log:** Displays previous game outcomes with visual color indicators (Emerald for Win, Crimson for Loss, Gold for Draw).
- **Victory Celebrations:** Integrates `canvas-confetti` to celebrate your wins!
- **Fully Responsive:** Smoothly adapts to all screen sizes from desktop monitors to mobile phones.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic web structure.
- **CSS3:** Custom properties (CSS variables), CSS Grid, Flexbox, and smooth hover state animations.
- **JavaScript (ES6+):** Modular game logic, DOM manipulation, and state management.
- **Third-Party Libraries:** [Canvas Confetti](https://github.com/catdad/canvas-confetti) for celebratory visual effects.
